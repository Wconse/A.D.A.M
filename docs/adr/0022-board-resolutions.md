# ADR 0022: Deterministic board resolutions

- Status: Accepted foundation
- Date: 2026-07-21

Board decisions are explicit resolutions with proposer, corporate action, eligible director set, replaceable votes, quorum threshold, approval threshold, and terminal status. Abstentions count for quorum but not decisive votes. Non-directors and votes after closure are rejected. This model will be integrated into authoritative commands before resolutions can execute investments, dividends, or appointments.
