# ADR 0059: Advisory cash-constrained staffing

- Status: Accepted foundation
- Date: 2026-07-23

Realized payroll coverage can produce a staffing proposal proportional to wages actually paid versus owed. The planner is advisory: it never fires workers automatically. A manager or AI actor must decide whether to execute the proposed employment command using expectations, contracts, politics, and strategy. This preserves causal evidence without turning low cash into a magic layoff rule.
