# ADR 0054: Causal state versus descriptive indicators

- Status: Accepted
- Date: 2026-07-23

Crisis, living standards, deprivation indices, stability, unemployment rates, and inflation are descriptions derived from concrete state, not causal debuffs. Simulation rules operate on physical stocks and flows, money, jobs, health, knowledge, expectations, relationships, institutions, and attributed memories. Generic indicators remain analytics only. Cohort memory records concrete durations such as survival shortage, unemployment, and debt distress.
