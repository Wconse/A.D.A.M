# ADR 0040: Authoritative logistics terminals

- Status: Accepted foundation
- Date: 2026-07-22

Terminals are physical regional assets operated by firms. They define daily handling throughput, storage price per quantity-day, and base handling duration. Shared capacity is reserved and released explicitly. Terminals and usage are authoritative World state with save/replay and fingerprint coverage. Queueing and intermodal shipment integration remain subsequent layers.
