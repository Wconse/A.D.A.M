# Step 100 anniversary acceptance — The Governing State Becomes Visible

## Accepted scope

- Persistent government-program promise and charter.
- Treasury, public-debt, zero-funding, and cancellation choices.
- Administrative, infrastructural, political, material, and labor execution constraints.
- Physical public-reserve consumption and temporary household wages.
- Regional beneficiaries, underfulfilled promises, exclusions, and accumulated political memory.
- Annual satisfaction, legitimacy, polarization, and elite-cohesion consequences.
- Shared deterministic program chronicle.
- Independent Bevy observatory with map, inspector, overlays, program desk, and timeline.
- Command/replay equality across authoritative fingerprints and complete observatory snapshots.

## Run

```text
cargo run -p adam-observatory
```

Controls:

- `1`, `2`, `3`: confidence, population, and output overlays.
- `Tab`: inspect the next region.
- `T`: request treasury appropriation.
- `D`: request debt appropriation.
- `E`: execute the program.
- `C`: cancel the program.
- `Y`: advance one economic year.

Rejected choices are displayed and do not mutate the world.
